# 模块状态

## 已实现并有当前回归证据

- 登录、角色会话、运营/主播审批、超级管理员审批入口。
- 主播独立聊天作用域、维护对象/消息编辑删除、候选保存和回复历史。
- 来源消息服务端校验、对象切换清理、旧异步生成结果丢弃。
- 维护任务、运营点评、只读主播工作台、审计和使用统计。
- 智谱 GLM-5.3 provider 配置、脱敏 API 测试和 Runtime 结构化适配。
- 统一测试 runner、Node 22 版本约束和独立副本生产构建。
- 管理员初始化脚本的幂等与单实例安全边界。
- 登录、注册和游客登录的服务端窗口限流：按来源与规范化账号建立不可逆桶，超限返回 429、`Retry-After` 和脱敏错误码；未开启可信代理时不信任客户端转发地址。
- 真实浏览器回归的隔离前置条件、断言清单和失败证据记录。
- 认证默认策略：生产环境未显式配置时要求登录，开发环境保持预览兼容；健康检查、AI 入口和相关接口共用同一策略函数。
- 数据库迁移账本：`schema_migrations` 基线、checksum 一致性校验、幂等重开和重复版本保护。
- SQLite 一致性备份工具：在线 backup、完整性检查、迁移账本校验、源库不改写和默认拒绝覆盖。
- 管理员发起的一次性密码恢复：仅活动超级管理员可为运营/主播签发短时 token；数据库只保存 token hash，消费后单次失效并撤销目标账号全部会话，审计不记录密码或原 token。
- Windows 10 局域网部署前置契约：显式校验 Node 版本、生产认证、独立数据库路径、监听地址和端口；PowerShell/cmd 启停入口不打印密钥，停止脚本默认只检查并要求显式确认。
- Runtime 唯一入口：旧首页与 `/chat` 的正式生成均经由服务端 `goutoujunshi Runtime → GLM-5.3`；浏览器不再提交关系状态作为分析输入，服务端按当前账号和来源消息重建上下文。
- Runtime UI 投影：旧首页的正式分析卡片只接受服务端 `analysis`/`relationshipState` 投影，生成等待和失败时清空旧状态；本地辅助判断不会再冒充当前 Runtime 结果。
- 回复历史 Runtime 上下文：候选历史同时保存 `analysis`、`intake`、Runtime 元数据、开场话题和直播邀请；登录用户走 SQLite migration/API，游客走独立 localStorage 命名空间，恢复历史时一次性还原候选与分析依据。
- 浏览器回归安全前置：真实浏览器驱动启动前会拒绝 3102、正式数据库、非回环地址、provider key 和 Cookie，并只输出脱敏安全摘要。
- Agent Browser 冒烟适配：可选命令只打开临时服务登录页并校验 origin，默认关闭且不接收账号、Cookie 或 API Key。

- 数据库升级回滚、Windows 10 定时备份/异地存储、恢复演练和断电恢复；当前只完成迁移账本与可验证备份副本契约。
