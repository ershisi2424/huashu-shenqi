# 超级管理员生成与恢复

## 当前脚本

```powershell
$env:AUTH_DB_PATH = "C:\Huashu\data\auth.sqlite"
$env:BOOTSTRAP_ADMIN_PHONE = "13800138000"
$env:BOOTSTRAP_ADMIN_PASSWORD = "在密码管理器中生成的长密码"
$env:BOOTSTRAP_ADMIN_NAME = "最高管理员"
node scripts/bootstrap-admin.cjs
```

脚本调用服务端 `ensureBootstrapAdmin`，只保存不可逆密码哈希，不会把密码写回数据库或响应。生产部署前必须通过受保护的环境变量/密码管理器注入，执行后清理当前进程环境。

## 当前限制

- 生成脚本现在对同一活动最高管理员幂等；数据库中已有任何最高管理员时拒绝新手机号，已有其他角色手机号时拒绝提升，并以非零退出码返回。
- 运营/主播账号的受保护密码恢复已通过管理员接口提供：由活动超级管理员签发短时一次性令牌，目标账号消费后撤销全部会话并写入审计；不能通过重复运行初始化脚本绕过。
- 超级管理员页面可审批运营/主播、查看审计、管理用户和查看使用统计，但不应显示任何用户明文密码。
- 真实恢复通知、密钥轮换、管理员失联处理和审计留痕尚未在 Windows 10 实机演练；恢复令牌不应通过公开聊天、日志或截图传递。
