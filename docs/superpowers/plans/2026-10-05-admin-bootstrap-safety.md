# 超级管理员初始化安全阶段

## 验收契约

- 同一活动最高管理员重复初始化返回同一账号，不改名、不改密码。
- 数据库已有任意最高管理员时，新手机号初始化必须失败。
- 初始化手机号已属于运营或主播时必须失败，不能提升角色。
- CLI 失败使用非零状态和脱敏提示，不打印密码、token 或数据库内容。
